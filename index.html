Common questions

An app is still blocked after I removed it from a profile. Open getIRL once; it repairs blocks each time it opens. If it is still blocked, go to iPhone Settings → Screen Time, switch getIRL's access off and on again.

Blocks don't start. getIRL needs Screen Time access. Open the app; it asks for access if it is off.

I didn't see the unlock notification. Notifications can be silenced by a Focus mode. Open getIRL within 10 minutes of tapping "Ask to unlock" and the countdown opens by itself.

Can getIRL be switched off? Yes. You stay in charge: Screen Time access can be turned off in Settings with Face ID or your passcode. getIRL notes it in History, without judgement.
